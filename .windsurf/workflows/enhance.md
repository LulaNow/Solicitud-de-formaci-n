# /enhance - Improve Existing Code

## Purpose

Improve existing code with better patterns, performance optimizations, or additional features.

## Steps

1. **Analyze Current State**
   - Review existing code
   - Identify improvement areas
   - Check for anti-patterns
   - Measure current performance

2. **Plan Improvements**
   - List specific enhancements
   - Prioritize by impact
   - Consider breaking changes
   - Plan migration strategy if needed

3. **Implement Enhancements**
   - Apply improvements incrementally
   - Maintain backward compatibility when possible
   - Add/update tests
   - Document changes

4. **Verify Improvements**
   - Run test suite
   - Measure performance gains
   - Check for regressions
   - Update documentation

## Enhancement Categories

### Performance
- Optimize bundle size
- Eliminate waterfalls
- Improve rendering performance
- Add caching strategies

### Code Quality
- Refactor complex functions
- Improve type safety
- Remove code duplication
- Apply design patterns

### Features
- Add new functionality
- Improve user experience
- Enhance accessibility
- Add error handling

### Security
- Fix vulnerabilities
- Improve authentication
- Add input validation
- Update dependencies

## Examples

```
/enhance improve performance of dashboard
/enhance add error handling to API routes
/enhance refactor user authentication
/enhance optimize image loading
```

## Key Principles

- **Measure first** - profile before optimizing
- **Test thoroughly** - ensure no regressions
- **Document changes** - explain what and why
- **Incremental improvements** - small, focused changes
