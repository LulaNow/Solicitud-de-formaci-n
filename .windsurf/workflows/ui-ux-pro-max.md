# /ui-ux-pro-max - Premium UI/UX Design

## Purpose

Create exceptional, memorable UI/UX designs that break conventions and deliver premium user experiences.

## Deep Design Thinking (MANDATORY)

### Before Any Design Work

**⛔ DO NOT start designing until you complete this analysis!**

#### 1. Context Analysis (Internal)

```
🔍 CONTEXT:
├── Sector? → What emotions should it evoke?
├── Target audience? → Age, tech-savviness, expectations?
├── Competitors? → What should I NOT do?
└── Soul of this site/app? → In one word?

🎨 DESIGN IDENTITY:
├── What will make this UNFORGETTABLE?
├── What unexpected element can I use?
├── How do I avoid standard layouts?
├── 🚫 CLICHÉ CHECK: Bento Grid? Mesh Gradient? (IF YES → CHANGE!)
└── Will I remember this in a year?

📐 LAYOUT HYPOTHESIS:
├── How can the Hero be DIFFERENT?
├── Where can I break the grid?
├── Which element can be in unexpected place?
└── Can Navigation be unconventional?

🎭 EMOTION MAPPING:
├── Primary emotion: [Trust/Energy/Calm/Luxury/Fun]
├── Color implication: [Blue/Orange/Green/Black-Gold/Bright]
├── Typography character: [Serif=Classic, Sans=Modern, Display=Bold]
└── Animation mood: [Subtle=Professional, Dynamic=Energetic]
```

#### 2. Modern Cliché Scan (ANTI-SAFE HARBOR)

**Forbidden defaults:**
- ❌ "Standard Split" (Left Text / Right Visual)
- ❌ Bento Grids for landing pages
- ❌ Mesh/Aurora Gradients
- ❌ Glassmorphism abuse
- ❌ Deep Cyan / Fintech Blue
- ❌ Generic copy ("Orchestrate", "Empower", "Elevate")
- ❌ **PURPLE** (AI cliché color)

#### 3. Topological Hypothesis

Pick a radical path:

- **[ ] FRAGMENTATION**: Overlapping layers, zero vertical/horizontal logic
- **[ ] TYPOGRAPHIC BRUTALISM**: Text is 80% visual weight
- **[ ] ASYMMETRIC TENSION (90/10)**: Visual conflict, extreme corner
- **[ ] CONTINUOUS STREAM**: No sections, flowing narrative

## Layout Diversification

**Break the "Split Screen" habit:**

### Alternative Structures

1. **Massive Typographic Hero**
   - Center headline, 300px+
   - Build visual behind/inside letters

2. **Experimental Center-Staggered**
   - Every element different horizontal alignment
   - L-R-C-L pattern

3. **Layered Depth (Z-axis)**
   - Visuals overlap text
   - Partially unreadable but artistically deep

4. **Vertical Narrative**
   - No "above the fold" hero
   - Vertical flow of fragments

5. **Extreme Asymmetry (90/10)**
   - Compress to one extreme edge
   - 90% negative/dead space for tension

## Visual Style Variety

### Geometry Extremism

**🚫 AVOID THE "SAFE BOREDOM" ZONE (4px-8px)**

Go extreme:
- **0px - 2px**: Tech, Luxury, Brutalist (Sharp/Crisp)
- **16px - 32px**: Social, Lifestyle, Bento (Friendly/Soft)

Every project should have DIFFERENT geometry.

### Animation Requirements (MANDATORY)

**STATIC DESIGN IS FAILURE**

#### Mandatory Layered Animations

1. **Reveal**: Scroll-triggered entrance animations (staggered)
2. **Micro-interactions**: Physical feedback on hover/click
3. **Spring Physics**: Organic, not linear animations

#### Mandatory Visual Depth

- Overlapping Elements
- Parallax Layers
- Grain Textures
- NO Mesh Gradients (unless specifically requested)
- NO Glassmorphism abuse

#### Optimization Mandate

- GPU-accelerated properties only (`transform`, `opacity`)
- Strategic `will-change` usage
- `prefers-reduced-motion` support MANDATORY

## The Trinity (Every Design Must Achieve)

1. ✅ **Sharp/Net Geometry** (Extremism)
2. ✅ **Bold Color Palette** (No Purple)
3. ✅ **Fluid Animation & Modern Effects** (Premium Feel)

## UI Library Rules

### ⛔ NO DEFAULT UI LIBRARIES

**NEVER automatically use shadcn, Radix, or any component library without asking!**

**ALWAYS ask first:** "Which UI approach do you prefer?"

Options:
1. **Pure Tailwind** - Custom components, no library
2. **shadcn/ui** - If user explicitly wants it
3. **Headless UI** - Unstyled, accessible
4. **Radix** - If user explicitly wants it
5. **Custom CSS** - Maximum control
6. **Other** - User's choice

## The Maestro Auditor (Self-Audit)

Before confirming completion, verify against these rejection triggers:

| 🚨 Rejection Trigger | Corrective Action |
|---------------------|-------------------|
| **The "Safe Split"** | Switch to 90/10, 100% Stacked, or Overlapping |
| **The "Glass Trap"** | Remove blur, use solid colors and raw borders |
| **The "Glow Trap"** | Use high-contrast solid colors or grain textures |
| **The "Bento Trap"** | Fragment the grid, break alignment intentionally |
| **The "Blue Trap"** | Switch to Acid Green, Signal Orange, or Deep Red |

**🔴 MAESTRO RULE**: "If I can find this layout in a Tailwind UI template, I have failed."

## Reality Check (Anti-Self-Deception)

### The "Template Test" (Brutal Honesty)

| Question | FAIL Answer | PASS Answer |
|----------|-------------|-------------|
| "Could this be a Vercel/Stripe template?" | "Well, it's clean..." | "No way, this is unique" |
| "Would I scroll past on Dribbble?" | "It's professional..." | "I'd stop and think 'how?'" |
| "Describe without 'clean' or 'minimal'?" | "It's... clean corporate" | "Brutalist with aurora accents" |

### Honest Reality Checks

1. **Screenshot Test**: Designer says "template" or "interesting"?
2. **Memory Test**: Will users remember this tomorrow?
3. **Differentiation Test**: Name 3 things that make this DIFFERENT
4. **Animation Proof**: Do things MOVE or is it static?
5. **Depth Proof**: Actual layering or flat?
