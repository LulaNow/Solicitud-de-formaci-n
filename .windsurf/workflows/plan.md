# /plan - Task Breakdown & Planning

## Purpose

Create a detailed task breakdown and project plan with milestones and dependencies.

## Steps

1. **Understand Requirements**
   - Clarify project goals
   - Identify stakeholders
   - Define success criteria
   - List constraints

2. **Break Down Tasks**
   - Decompose into manageable tasks
   - Identify dependencies
   - Estimate effort
   - Set priorities

3. **Create Timeline**
   - Define milestones
   - Set realistic deadlines
   - Account for risks
   - Plan iterations

4. **Document Plan**
   - Create structured plan document
   - Include task list
   - Add technical decisions
   - Document assumptions

## Plan Structure

```markdown
# Project Plan: [Project Name]

## Overview
[Brief description and goals]

## Success Criteria
- [ ] Criterion 1
- [ ] Criterion 2

## Tech Stack
- Frontend: [technology]
- Backend: [technology]
- Database: [technology]
- Deployment: [platform]

## Tasks

### Phase 1: Foundation
- [ ] Task 1 (2h)
- [ ] Task 2 (4h)

### Phase 2: Core Features
- [ ] Task 3 (6h)
- [ ] Task 4 (3h)

### Phase 3: Polish
- [ ] Task 5 (2h)
- [ ] Task 6 (1h)

## Milestones
1. **Week 1**: Foundation complete
2. **Week 2**: Core features working
3. **Week 3**: Production ready

## Risks & Mitigation
- Risk 1: [mitigation strategy]
- Risk 2: [mitigation strategy]

## Assumptions
- Assumption 1
- Assumption 2
```

## Examples

```
/plan e-commerce website
/plan mobile app for task management
/plan API migration to GraphQL
/plan database optimization
```

## Key Principles

- **Be realistic** - don't underestimate effort
- **Include buffer** - account for unknowns
- **Prioritize ruthlessly** - focus on MVP first
- **Document decisions** - explain technical choices
- **Stay flexible** - plans change, adapt
