## 🔧 Advanced Usage

### Turbo Mode

Some workflow steps have `// turbo` annotation, allowing safe auto-run:

```markdown
// turbo
1. Run tests
```

This step will execute automatically without confirmation.

### Chaining Workflows

```
/plan e-commerce site
# Review plan, then:
/create [based on plan]
# Build complete, then:
/test
# Tests pass, then:
/deploy
```

### Custom Workflows

Add your own in `.windsurf/workflows/`:

```markdown
---
description: Your custom workflow
---

# /custom - Custom Workflow

## Steps
1. Step one
// turbo
2. Step two (auto-runs)
```

## 🐛 Troubleshooting

### Workflows not showing up?

1. Restart Windsurf
2. Check `.windsurf/workflows/` exists
3. Verify file format (YAML frontmatter + markdown)

### Rules not being followed?

1. Check `.windsurf/rules/` exists
2. Rules are always active (no need to invoke)
3. Restart Windsurf if needed

### Want to customize?

1. Edit existing workflows in `.windsurf/workflows/`
2. Add new rules in `.windsurf/rules/`
3. See `ARCHITECTURE.md` for details
