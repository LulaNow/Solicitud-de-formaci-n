# ⚡ Quick Start - Windsurf Superpowers

> Get started in 60 seconds!

---

## 🚀 First Steps

### 1. Restart Windsurf
Close and reopen Windsurf to load your new superpowers.

### 2. Try Your First Command

```
/status
```

This will check your project health and show you what's available.

### Create Something New
```
/create todo app with authentication
/create landing page for SaaS product
/create REST API for blog
```


### Plan Projects

## 💡 Pro Tips

### Tip 1: Chain Commands
```
/plan blog platform
# Review plan, then:
/create blog platform
# Build complete, then:
/test
# Tests pass, then:
/deploy
```

### Tip 2: Use `/brainstorm` Before Building
```
/brainstorm authentication strategy for multi-tenant app
# Explore 3+ options, then choose best approach
```

### Tip 3: Regular Health Checks
```
/status
# Run weekly to catch issues early
```

### Tip 4: Trust the Anti-Cliché System
```
/ui-ux-pro-max design landing page
# Will create unique, memorable designs (no templates!)
```

### Tip 5: Complex Tasks? Use `/orchestrate`
```
/orchestrate build secure payment system
# Coordinates security, backend, frontend, testing
```

## 🆘 Need Help?

### Workflows Not Showing?
1. Restart Windsurf
2. Check `.windsurf/workflows/` exists
3. Try typing `/` to see available commands

### Rules Not Working?
Rules are **always active** - no need to invoke them!
They automatically enforce quality standards.

### Want to Customize?
Edit files in `.windsurf/workflows/` and `.windsurf/rules/`
